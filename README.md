# Bare-metal LED Blink on STM32F446RE (NUCLEO)

Проект демонстрирует управление GPIO на микроконтроллере STM32F446RE без использования HAL и CubeMX. Светодиод мигает за счёт прямого обращения к регистрам периферии.

## Особенности реализации

- **Прямое управление регистрами**: RCC (AHB1ENR), GPIO (MODER, OTYPER, OSPEEDR, PUPDR, BSRR).
- **Атомарное переключение пина**: используется регистр BSRR для установки и сброса без операций чтения-изменения-записи.
- **Читаемость вместо комментариев**: логика работы с битами вынесена в именованные константы (`PA5_PIN`, `PA5_SHIFT`).
- **Зависимость задержки от частоты**: задержка реализована как количество тактов (NOP), что наглядно показывает связь между частотой ядра и временем выполнения.

> Примечание: светодиод подключён к пину PA5 (пользовательская конфигурация: макетка / Wokwi). На стандартной плате NUCLEO‑F446RE штатный светодиод LD2 находится на PD12.

## Технические детали

- MCU: STM32F446RE
- Плата: NUCLEO-F446RE
- Инструменты: STM32CubeIDE, GCC
- Язык: C

## Как запустить

1. Открыть проект в STM32CubeIDE.
2. Build → Run.
3. Светодиод на PA5 должен начать мигать.

## Что показывает этот проект

Этот проект подтверждает умение работать с низкоуровневой периферией STM32: понимать дерево тактирования, настраивать GPIO по регистрам и писать чистый, поддерживаемый код без абстракций HAL.
